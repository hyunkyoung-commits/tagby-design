Meta 8월 광고 주요 변경사항 정리

EU AI 공개 의무 시행, Insights API 브레이크다운 옵트인 전환, 제외 오디언스 공식 지원

Meta가 2026년 8월 중 광고 플랫폼 전반에 걸쳐 몇 가지 주요 변경을 진행했습니다.

정책 의무화, API 구조 변경, 오디언스 기능 추가가 핵심 내용입니다.

EU AI Act — AI 생성 광고 소재 공개 라벨 의무화

2026년 8월 2일부터 EU AI Act의 투명성 의무가 광고에도 적용되기 시작했습니다.

AI가 생성하거나 AI로 크게 수정된 소재를 EU 사용자에게 노출하는 경우, 해당 광고에 공개 라벨을 붙여야 합니다.

딥페이크 스타일의 이미지나 영상이 포함된 광고가 주요 적용 대상입니다.

EU 외 지역은 현재 이 요건이 강제되지 않지만, 글로벌 캠페인을 운영 중이라면 소재 분류 기준을 정리해두는 것이 좋습니다.

Ads Insights API 브레이크다운 — 옵트인 방식으로 전환

8월 6일부터 Ads Insights API의 일부 브레이크다운 데이터가 기본 제공에서 옵트인 방식으로 변경됐습니다.

영향을 받는 항목은 impression_device, hourly_stats, frequency_value 세 가지입니다.

광고 리포팅 자동화 도구나 서드파티 분석 툴을 사용 중이라면 데이터 누락 여부를 확인해야 합니다. API를 통한 성과 데이터 수집 체계를 운영 중이라면 옵트인 설정 여부를 점검하시기 바랍니다.

제외 전용 Custom Audience 공식 지원

Meta가 노출 제외 목적으로만 설정하는 Custom Audience를 공식으로 지원하기 시작했습니다.

기존 고객이나 특정 행동을 한 사용자를 광고 노출에서 제외하는 작업이 보다 명확한 방식으로 가능해졌습니다.

리타겟팅 캠페인에서 이미 전환된 사용자를 제외하거나, 특정 세그먼트에 광고가 반복 노출되는 것을 방지하는 데 유용합니다.
