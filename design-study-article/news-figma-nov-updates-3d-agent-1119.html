Figma 11월 업데이트 총정리: 3D·모션·에이전트가 한꺼번에

AI 선택 도구부터 3D 트랜스폼, Dev Mode 에이전트까지 공식 릴리스 노트 7건

Figma가 11월 한 달 동안 공식 릴리스 노트에 디자인 관련 업데이트 7건을 올렸습니다.

나열하면 많아 보이지만 ‘만들고, 움직이고, 코드로 넘기는’ 하나의 흐름으로 묶입니다.

11월 릴리스 노트 정리

11/5 에이전트 생성 벡터 개선. 에이전트가 만든 일러스트·아이콘이 독립적이고 자연스럽게 묶인 레이어로 나옵니다. 참고 이미지로 스타일을 맞출 수 있고, 선은 채우기가 아닌 스트로크라 굵기와 끝 모양을 바꿀 수 있습니다. Figma Motion에서 바로 애니메이션을 줄 수 있을 만큼 정리됐다고 합니다.

11/6 AI 이미지 편집 선택. Select area에서 객체를 클릭하면 자동으로 선택됩니다. 윤곽을 손으로 따라 그릴 필요가 없고, macOS 데스크톱 앱에서만 쓸 수 있습니다.

11/10 Motion 업데이트. 질량·강성·감쇠를 조절하는 물리 기반 스프링, 스타일 미리보기, Lottie 내보내기 미리보기가 추가됐습니다. 스프링은 iOS·Android용으로 설정됩니다.

11/12 3D 트랜스폼. x·y·z 축 회전과 원근·깊이 조절을 캔버스 핸들로 다루고, Figma 에이전트가 3D 디자인을 구성할 수도 있습니다. Motion과 함께 카드 뒤집기 같은 동작을 만들고, Dev Mode에서 CSS를 복사하거나 MCP로 코딩 에이전트에 넘길 수 있습니다.

11/17 승인 앱 허용 목록. 관리자가 Cursor, Claude Code 같은 MCP 클라이언트를 포함한 OAuth 앱을 허용·관리하는 Extensions 탭이 생겼습니다. 조직·엔터프라이즈 플랜에 순차 적용 중입니다.

11/18 이미지 다중 생성. Make image와 Edit image에서 한 번의 프롬프트로 2·4·6장을 만들거나, 최대 3개 모델이 각각 한 장씩 만들어 비교할 수 있습니다.

11/19 Dev Mode의 Figma 에이전트. Dev Mode에서 에이전트에게 디자인을 살펴보게 하고, 버전을 비교하고, 코드 스니펫을 요청하고, 에셋을 한꺼번에 내려받는 링크를 받을 수 있습니다. 플랜과 제한은 릴리스 노트에 명시돼 있지 않습니다.

에이전트가 디자인에서 코드까지 이어 붙는다

아래는 릴리스 노트를 토대로 한 TAGby의 해석입니다.

벡터·3D·이미지 생성은 ‘만드는’ 단계, Motion은 ‘움직이는’ 단계, Dev Mode 에이전트와 MCP는 ‘넘기는’ 단계에 해당합니다. 11월 업데이트는 이 세 단계 모두에 에이전트를 끼워 넣은 모양새입니다.

같은 달 Adobe는 챗봇에서 Creative Cloud를 부르는 MCP를 내놨습니다. Figma는 캔버스 안에서, Adobe는 바깥 챗봇에서 AI를 붙이는 방향으로 갈리는 구도는 Adobe MAX 2026 글에서 다뤘습니다. Figma의 AI 크레딧 정책은 Q3 실적 글에서 볼 수 있습니다.

11/17 허용 목록은 눈에 덜 띄지만 의미가 있습니다. 에이전트와 MCP 클라이언트를 조직에서 쓰려면 어떤 앱을 연결할지 관리자가 통제할 수 있어야 하기 때문입니다.

실무 체크포인트

3D 트랜스폼은 정지 이미지보다 Motion과 함께 쓸 때 효과가 큽니다. 카드 뒤집기, 제품 회전 같은 시안으로 먼저 시험해 보세요.

에이전트 생성 벡터는 레이어 이름, 스트로크 일관성, 브랜드 컬러 일치 여부를 확인하고 쓰는 것이 좋습니다.

Select area 자동 선택은 macOS 전용입니다. 팀 환경이 섞여 있다면 먼저 확인하세요.

Dev Mode 에이전트가 만든 코드는 개발자 리뷰를 거치고, 디자인 시스템 토큰이 반영됐는지 점검해야 합니다.

참고로 릴리스 노트에는 이 밖에 FigJam 모바일 개선도 올라와 있지만, 이번 글에서는 디자인 작업과 직접 관련된 항목만 골랐습니다.

Q. Figma의 AI 객체 자동 선택은 Windows에서도 쓸 수 있나요?

A. 11월 6일 릴리스 노트는 해당 기능을 macOS 데스크톱 앱에서만 쓸 수 있다고 밝혔습니다.

Q. Figma 3D 트랜스폼으로 무엇을 할 수 있나요?

A. x·y·z 축 회전과 원근·깊이 조절을 캔버스에서 직접 할 수 있고, Motion과 함께 카드 뒤집기 같은 동작을 만들어 Dev Mode에서 CSS를 복사하거나 MCP로 코딩 에이전트에 넘길 수 있습니다.

Q. Dev Mode의 Figma 에이전트는 무엇을 해 주나요?

A. 디자인을 살펴보고 이해하게 하고, 버전을 비교하고, 코드 스니펫을 요청하고, 에셋을 한꺼번에 내려받는 링크를 받을 수 있습니다. 플랜과 제한은 릴리스 노트에 명시돼 있지 않습니다.
